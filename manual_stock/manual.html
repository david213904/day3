왜 여기서도 FastAPI + Railway인가

  • 장중 내내 혼자 모아야 합니다. 아무도 사이트를 안 열어도 1시간마다 새 봉이 쌓여야 그래프에 구멍이 없습니다.
  • 파이썬 도구가 필요합니다. yfinance와 pandas(이동평균 rolling, 등락률 pct_change)는 브라우저에서 못 씁니다.
  • 계산은 한 번만. 서버가 지표까지 계산해 저장하면, 화면 100개가 열려도 각자 계산하지 않고 결과만 받습니다.
  • 나중에 증권사 API로 바꿀 때 그 키도 Railway Variables에만 둡니다. 화면 코드는 바뀌지 않습니다.

“실시간”은 어디까지인가

방식얼마나 자주이 실습과의 관계
증권사 실시간(웹소켓)체결될 때마다 (1초에도 여러 번)계좌·키 발급이 필요해서 이번엔 제외 (8장 응용)
yfinance 1시간 봉1시간 단위, 15~20분 지연이번 실습. 장 시간(09:00~15:30)에 하루 6~7개 봉
공공데이터포털 주식시세하루 1번 (전날 종가)1시간 그래프는 못 그림

미세먼지도 한 시간에 한 번 갱신되는 데이터였습니다. 공공·무료 데이터는 대부분 이렇게 정해진 간격으로 갱신되고, 그래서 서버가 같은 간격으로 계속 받아 쌓는 것이 백엔드의 일입니다. 화면의 1분 새로고침은 “서버가 새 봉을 쌓았는지 확인하는 것”입니다.

공개 사이트 주의: 거래소 시세는 다시 배포하는 데 제한이 있습니다. 수업에서는 Vercel 주소를 수강생끼리만 공유하거나 연습 모드(DEMO_MODE=1)로 운영하세요.

3Supabase 테이블 만들기

Supabase → SQL Editor → New query → 붙여 넣고 Run. 1편과 같은 프로젝트를 써도 됩니다. 테이블 이름이 달라서 섞이지 않습니다.

수집 기록 테이블 이름은 stock_logs라서 1편의 collect_logs와 겹치지 않습니다.
schema.sql
-- Supabase → SQL Editor 에 붙여 넣고 Run
create table if not exists candles (
  id          bigint generated always as identity primary key,
  source      text not null,                 -- 'yfinance'(진짜) / 'demo'(연습)
  ticker      text not null,                 -- 005930.KS
  name        text,                          -- 삼성전자
  ts          timestamptz not null,          -- 봉 시작 시각 (1시간 단위)
  open        bigint, high bigint, low bigint, close bigint,
  volume      bigint,
  change_pct  real,                          -- 직전 봉 대비 등락률 %  (FastAPI가 계산)
  ma5         real,                          -- 5시간 이동평균
  ma20        real,                          -- 20시간 이동평균
  signal      text,                          -- 골든크로스 / 데드크로스 / 급변동
  collected_at timestamptz not null default now(),
  unique (source, ticker, ts)                -- 같은 봉은 덮어쓰기 (중복 방지)
);

create table if not exists stock_logs (
  id       bigint generated always as identity primary key,
  ran_at   timestamptz not null default now(),
  source   text,
  tickers  int,      -- 종목 수
  fetched  int,      -- 받은 봉 수
  dropped  int,      -- 버린 봉 수
  cleaned  int,      -- 정리된 봉 수
  saved    int,      -- 저장(덮어쓰기 포함)된 봉 수
  error    text      -- 실패한 종목 메시지
);

-- 브라우저에서 직접 못 건드리게 잠금. FastAPI는 secret 키라서 통과.
alter table candles enable row level security;
alter table stock_logs enable row level security;

Railway에 넣을 값: Project Settings → Data API의 Project URL(SUPABASE_URL), API Keys의 Secret key sb_secret_…(SUPABASE_SECRET_KEY). secret 키는 서버 전용입니다.

  1. railway.com → New Project → Deploy from GitHub repo → stock-api
  2. 서비스 → Variables → Raw Editor에 붙여 넣고 값 바꾸기 → Update Variables → 위에 뜨는 Deploy

변수뜻
TICKERS모을 종목(쉼표). 종목이 많을수록 수집 시간이 길어지니 수업에선 3~5개

SPIKE_PCT한 시간에 몇 % 이상 움직이면 “급변동”으로 표시할지
COLLECT_MINUTES자동 수집 간격(분). 1시간 봉이므로 60이면 충분, 더 빨리 반영하려면 15~30

src/StockDemo.jsx
// Vercel 프론트(React)에 넣는 화면 — 그래프용 데이터만 Railway에 물어본다 (라이브러리 없이 SVG)
import { useEffect, useState } from "react";

const API = import.meta.env.VITE_API_URL;
const W = 640, H = 300, PAD = 40;

function Chart({ candles }) {
  if (!candles.length) return null;
  const vals = candles.flatMap((c) => [c.close, c.ma5, c.ma20]).filter((v) => v != null);
  const min = Math.min(...vals), max = Math.max(...vals);
  const x = (i) => PAD + (i * (W - PAD * 2)) / Math.max(1, candles.length - 1);
  const y = (v) => H - PAD - ((v - min) / Math.max(1, max - min)) * (H - PAD * 2);
  const line = (key) =>
    candles.map((c, i) => (c[key] == null ? null : `${x(i)},${y(c[key])}`)).filter(Boolean).join(" ");
  const mark = { 골든크로스: "#27ae60", 데드크로스: "#eb5757", 급변동: "#f2994a" };

  return (
    <svg viewBox={`0 0 ${W} ${H}`} style={{ width: "100%", background: "#fff", border: "1px solid #ddd" }}>
      <text x={PAD} y={20} fontSize="12">{max.toLocaleString()}원</text>
      <text x={PAD} y={H - 8} fontSize="12">{min.toLocaleString()}원</text>
      <polyline points={line("close")} fill="none" stroke="#0d8784" strokeWidth="2" />
      <polyline points={line("ma5")} fill="none" stroke="#3a82d2" strokeWidth="1.5" strokeDasharray="4 3" />
      <polyline points={line("ma20")} fill="none" stroke="#8e6bc9" strokeWidth="1.5" strokeDasharray="4 3" />
      {candles.map((c, i) =>
        c.signal ? <circle key={i} cx={x(i)} cy={y(c.close)} r="4" fill={mark[c.signal]} /> : null
      )}
    </svg>
  );
}

export default function StockDemo() {
  const [list, setList] = useState([]);
  const [ticker, setTicker] = useState("005930.KS");
  const [data, setData] = useState(null);
  const [error, setError] = useState("");

  async function load() {
    try {
      const [l, d] = await Promise.all([
        fetch(`${API}/stocks`).then((r) => r.json()),
        fetch(`${API}/stocks/${ticker}/candles?limit=120`).then((r) => r.json()),
      ]);
      setList(l);
      setData(d);
      setError("");
    } catch (e) {
      setError(String(e));
    }
  }

  // 처음 + 종목을 바꿀 때 + 1분마다 다시 물어보기 (서버는 1시간마다 새 봉을 저장)
  useEffect(() => {
    load();
    const id = setInterval(load, 60_000);
    return () => clearInterval(id);
  }, [ticker]);

  const last = data?.candles?.at(-1);
  return (
    <div style={{ padding: 20, maxWidth: 680 }}>
      <h3>주식 1시간 봉 (yfinance → FastAPI 가공 → Supabase)</h3>
      <p style={{ fontSize: 12, color: "#888" }}>교육용 예제 · 시세는 늦을 수 있음 · 투자 판단용 아님</p>
      {error && <p style={{ color: "red" }}>{error}</p>}
      <div style={{ display: "flex", gap: 8, flexWrap: "wrap" }}>
        {list.map((s) => (
          <button key={s.ticker} onClick={() => setTicker(s.ticker)}
            style={{ fontWeight: s.ticker === ticker ? 700 : 400 }}>
            {s.name} {s.ready && <span style={{ color: s.change_pct >= 0 ? "#d8443a" : "#3a82d2" }}>
              {s.change_pct >= 0 ? "▲" : "▼"}{Math.abs(s.change_pct ?? 0)}%</span>}
          </button>
        ))}
      </div>
      {last && (
        <p>
          <b>{data.name}</b> {last.close.toLocaleString()}원 · {last.time} 봉
          {data.mode === "demo" && <small> (연습 데이터)</small>}
        </p>
      )}
      {data?.candles && <Chart candles={data.candles} />}
      <p style={{ fontSize: 12 }}>
        <span style={{ color: "#0d8784" }}>━ 종가</span>{" "}
        <span style={{ color: "#3a82d2" }}>┅ 5시간 평균</span>{" "}
        <span style={{ color: "#8e6bc9" }}>┅ 20시간 평균</span>{" "}
        ● 신호(골든·데드크로스, 급변동)
      </p>
    </div>
  );
}
프론트에는 계산 코드가 없습니다. 이동평균도 신호도 서버가 이미 계산해 DB에 넣어 두었고, 화면은 받은 숫자로 선을 그릴 뿐입니다. 1편과 같은 역할 분리입니다.

7수업용 코드 읽기 포인트

7-1. 1시간 봉이란

한 시간 동안의 가격을 네 숫자로 줄인 것입니다: 시가(처음), 고가(가장 높음), 저가(가장 낮음), 종가(마지막). 그래프는 보통 종가를 잇습니다. 장중 마지막 봉은 아직 진행 중이라 다음 수집 때 값이 바뀌고, 같은 시각이라 덮어써집니다.

7-2. clean() 일곱 단계

#코드왜
1필요한 칸만, 소문자 이름yfinance는 배당·분할 칸도 줌 → DB 칸과 맞춤
2빈 종가·0 이하 버리기거래 정지·데이터 누락 봉은 선을 망침
3원화 → 정수199600.0 같은 소수점 제거
4한국 시간으로 통일 · 시간순 정렬DB와 화면 시각을 맞춤
5pct_change(), rolling(5), rolling(20)등락률·이동평균을 한 줄로 (pandas의 힘)
6평균선 위아래가 바뀐 순간 = 크로스, 큰 등락 = 급변동“계산된 정보”를 함께 저장
7DB 행(dict)으로빈값(NaN)은 None으로 바꿔야 저장됨

7-3. 이동평균과 크로스 (그림)

above   = ma5 > ma20                       # 지금 빠른 선이 위인가?
crossed = above != above.shift()           # 직전 봉과 위아래가 바뀌었나?
crossed & above   → "골든크로스"
crossed & ~above  → "데드크로스"

신호는 “이런 계산을 서버에서 한다”는 예시일 뿐, 맞는지 틀리는지 보장하지 않습니다.

7-4. 한 종목이 실패해도

main.py — 주식 1시간 봉 백엔드 (FastAPI)  ※ 교육용 예제, 투자 판단용 아님

Railway Variables

# ─────────── 수집 한 번 = 종목마다 받기 → 정리·지표 → 저장, 그리고 기록 ───────────
def run_collect() -> dict:
    total = {"fetched": 0, "dropped": 0, "cleaned": 0, "saved": 0}
    errors = []
    for t in TICKERS:
        try:
            raw = collect.fetch_demo(t) if DEMO else collect.fetch_yf(t)
            rows, st = collect.clean(raw, t, SOURCE, SPIKE)
            saved = store.save_candles(rows)
            for k in ["fetched", "dropped", "cleaned"]:
                total[k] += st[k]
            total["saved"] += saved
        except Exception as e:                      # 한 종목이 실패해도 나머지는 계속
            errors.append(f"{t}: {e}"[:200])
    entry = {"ran_at": datetime.now(timezone.utc).isoformat(), "source": SOURCE,
             "tickers": len(TICKERS), **total, "error": "; ".join(errors) or None}
    store.save_log(entry)
    log.info("collect %s", entry)
    return entry


async def auto_loop():
    """서버가 켜져 있는 동안 COLLECT_MINUTES 마다 자동 수집 (브라우저가 꺼져 있어도)"""
    while True:

            await asyncio.to_thread(run_collect)
        except Exception:
            log.exception("자동 수집 실패")
        await asyncio.sleep(MINUTES * 60)

"""
collect.py — ① 시세 받기  ② 가공(정리 + 지표 계산)

yfinance로 종목별 '1시간 봉'(시가·고가·저가·종가·거래량)을 받아서
pandas로 정리하고 등락률 · 이동평균 · 신호를 계산해 DB에 넣을 행으로 만든다.
※ 교육용 예제입니다. yfinance 시세는 15~20분 늦을 수 있고, 투자 판단용이 아닙니다.
"""
import random
from datetime import datetime, timedelta, timezone

import pandas as pd

KST = timezone(timedelta(hours=9))

NAMES = {"005930.KS": "삼성전자", "000660.KS": "SK하이닉스", "035420.KS": "NAVER",
         "035720.KS": "카카오", "005380.KS": "현대차"}


# ─────────────────────────────────────────────
# ① 받기 — yfinance (키 필요 없음)
# ─────────────────────────────────────────────
def fetch_yf(ticker: str) -> pd.DataFrame:
    """최근 한 달치 1시간 봉. 매번 한 달치를 받아 덮어쓰면 이동평균이 항상 정확하다."""
    import yfinance as yf
    df = yf.Ticker(ticker).history(period="1mo", interval="1h")
    if df.empty:
        raise RuntimeError(f"{ticker}: 시세가 비어 있습니다 (종목코드·장 휴일 확인)")
    return df


# ─────────────────────────────────────────────
# ①' 연습용 가짜 시세 — yfinance가 막혀도 실습할 수 있게
# ─────────────────────────────────────────────
def fetch_demo(ticker: str) -> pd.DataFrame:
    rnd = random.Random(ticker)                      # 종목마다 늘 같은 흐름
    price = {"005930.KS": 70000, "000660.KS": 180000}.get(ticker, 50000) * 1.0
    now = datetime.now(KST)
    day = (now - timedelta(days=31)).replace(hour=0, minute=0, second=0, microsecond=0)
    rows = []
    while day <= now:
        if day.weekday() < 5:                        # 평일만 장이 열림
            for h in range(9, 16):                   # 09시 ~ 15시 봉
                ts = day.replace(hour=h)
                if ts > now:
                    break
                o = price
                c = o * (1 + rnd.gauss(0.0003, 0.008))
                hi = max(o, c) * (1 + abs(rnd.gauss(0, 0.003)))
                lo = min(o, c) * (1 - abs(rnd.gauss(0, 0.003)))
                vol = int(abs(rnd.gauss(1, 0.4)) * 500000)
                rows.append({"Datetime": ts, "Open": o, "High": hi, "Low": lo, "Close": c, "Volume": vol})
                price = c
        day += timedelta(days=1)
    df = pd.DataFrame(rows).set_index("Datetime")
    # 진짜 데이터처럼 '덜 끝난 봉(거래량 0)'과 빈칸을 일부러 섞는다
    if len(df) > 10:
        df.iloc[-1, df.columns.get_loc("Volume")] = 0
        df.iloc[len(df) // 2, df.columns.get_loc("Close")] = float("nan")
    return df


# ─────────────────────────────────────────────
# ② 가공 — 정리 + 지표
# ─────────────────────────────────────────────
def clean(df: pd.DataFrame, ticker: str, source: str, spike_pct: float = 1.5):
    stats = {"fetched": len(df), "dropped": 0, "cleaned": 0}
    df = df.copy()

    # 1) 필요한 칸만, 이름은 소문자로
    df = df[["Open", "High", "Low", "Close", "Volume"]].rename(columns=str.lower)

    # 2) 종가가 비었거나 0 이하인 봉은 버린다
    before = len(df)
    df = df[df["close"].notna() & (df["close"] > 0)]
    stats["dropped"] = before - len(df)

    # 3) 원화는 소수점이 없다 → 정수로
    for col in ["open", "high", "low", "close"]:
        df[col] = df[col].round().astype("int64")
    df["volume"] = df["volume"].fillna(0).astype("int64")

    # 4) 시각을 한국 시간으로 통일하고 순서대로
    idx = pd.to_datetime(df.index)
    idx = idx.tz_localize(KST) if idx.tz is None else idx.tz_convert(KST)
    df.index = idx
    df = df.sort_index()

    # 5) 지표: 직전 봉 대비 등락률, 5시간·20시간 이동평균
    df["change_pct"] = (df["close"].pct_change() * 100).round(2)
    df["ma5"] = df["close"].rolling(5).mean().round(0)
    df["ma20"] = df["close"].rolling(20).mean().round(0)

    # 6) 신호: 이동평균이 엇갈린 순간 + 한 시간에 크게 움직인 순간
    above = df["ma5"] > df["ma20"]
    crossed = above.ne(above.shift()) & df["ma20"].notna() & df["ma20"].shift().notna()
    df["signal"] = None
    df.loc[crossed & above, "signal"] = "골든크로스"
    df.loc[crossed & ~above, "signal"] = "데드크로스"
    df.loc[df["signal"].isna() & (df["change_pct"].abs() >= spike_pct), "signal"] = "급변동"

    # 7) DB 행으로. 아직 진행 중인 마지막 봉도 넣지만, 다음 수집 때 같은 시각으로 덮어써진다
    rows = []
    for ts, r in df.iterrows():
        rows.append({
            "source": source, "ticker": ticker, "name": NAMES.get(ticker, ticker),
            "ts": ts.isoformat(),
            "open": int(r.open), "high": int(r.high), "low": int(r.low), "close": int(r.close),
            "volume": int(r.volume),
            "change_pct": None if pd.isna(r.change_pct) else float(r.change_pct),
            "ma5": None if pd.isna(r.ma5) else float(r.ma5),
            "ma20": None if pd.isna(r.ma20) else float(r.ma20),
            "signal": r.signal if isinstance(r.signal, str) else None,
        })
    stats["cleaned"] = len(rows)
    return rows, stats

"""
db.py — ④ 저장: Supabase (변수가 없으면 서버 메모리에 임시 저장)
"""
import os
from datetime import datetime, timedelta, timezone

KST = timezone(timedelta(hours=9))


def kst(ts: str) -> str:
    return datetime.fromisoformat(ts).astimezone(KST).strftime("%Y-%m-%d %H:%M")


class SupabaseStore:
    kind = "supabase"

    def __init__(self, url, key):
        from supabase import create_client
        self.sb = create_client(url, key)

    def save_candles(self, rows):
        if not rows:
            return 0
        saved = 0
        for i in range(0, len(rows), 500):           # 한 번에 너무 많이 보내지 않게 나눠서
            res = (self.sb.table("candles")
                   .upsert(rows[i:i + 500], on_conflict="source,ticker,ts").execute())
            saved += len(res.data or [])
        return saved

    def save_log(self, log):
        self.sb.table("stock_logs").insert(log).execute()

    def candles(self, source, ticker, limit=150):
        res = (self.sb.table("candles").select("*").eq("source", source).eq("ticker", ticker)
               .order("ts", desc=True).limit(limit).execute())
        return list(reversed(res.data))

    def logs(self, limit=20):
        res = (self.sb.table("stock_logs").select("*")
               .order("ran_at", desc=True).limit(limit).execute())
        return res.data


class MemoryStore:
    kind = "memory(임시)"

    def __init__(self):
        self.rows, self._logs = {}, []

    def save_candles(self, rows):
        for r in rows:
            self.rows[(r["source"], r["ticker"], r["ts"])] = r
        return len(rows)

    def save_log(self, log):
        self._logs.append(log)

    def candles(self, source, ticker, limit=150):
        rs = [r for r in self.rows.values() if r["source"] == source and r["ticker"] == ticker]
        return sorted(rs, key=lambda r: r["ts"])[-limit:]

    def logs(self, limit=20):
        return list(reversed(self._logs))[:limit]


def get_store():
    url = os.getenv("SUPABASE_URL", "").strip()
    key = os.getenv("SUPABASE_SECRET_KEY", "").strip()
    return SupabaseStore(url, key) if url and key else MemoryStore()
